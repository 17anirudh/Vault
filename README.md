## Overview

- **Vault** is a high performance financial application that provides to easily send money and manage your finances. 
- The main purpose of this project is to demonstrate that I can design scalable financial systems with double-entry accounting ledger with transactional guarantees using PostgreSQL ACID transactions, audit trails, and balance reconciliation in event driven architecture.

## Tech Stack

- Frameworks: Spring Boot (v4.0.6), Next.js (v16.2.7)
- Language: Java (v21), TypeScript (v6.0.3)
- Frontend: React (v19.2.7), Tailwind CSS (v4), Tanstack Query (v5.101.0)
- Backend: Spring Security, Spring Data JPA, Lombok, Validation
- Database: PostgreSQL (v16.10)
- Communication: RESTful API (Synchronous) and RabbitMQ (Asynchronous)
